TX500 Utility

A native macOS utility for the Lab599 Discovery TX-500

Pre-release — working and tested against a real radio, but still early. Back up your settings before restoring anything.

CAT control, memory channels, full settings backup and restore, clock sync and firmware updates — in one native Mac app. Backups are written in the same .set format as Lab599's own TRXSettings, and have been verified byte-for-byte against it.

RadioMenu 35 set to LAB599
TS-2000 mode cannot read or write settings

What it does

  • Live frequency, mode, S-meter and function state
  • All 100 memory channels, with .mem import and export
  • Settings backup, restore and a decoded viewer
  • Clock sync from the Mac
  • Firmware updates, with the steps spelled out
